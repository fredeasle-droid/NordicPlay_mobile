# DANSK Virtual Bodyguard

Standalone prototype for the DANSK Bodyguard concept.

## Preview
The intended GitHub Pages URL is:
https://fredeasle-droid.github.io/NordicPlay_mobile/bodyguard/

## Scope
- Private Vault prototype
- Telegram Helper
- Telegram username generator
- Creator / profile / mockup concepts
- Security Center
- VPN flow and status UI
- Wallet Bank
- Payment confirmation flow
- Quick Email
- URL shortener
- File converter
- QR generator
- AI Bodyguard chat shell

This directory is intentionally isolated from the existing DANSK eSIM frontend.

Important: VPN, real encrypted server-side storage, live AI, payment execution, email provisioning and file conversion require backend/provider integrations. The prototype does not pretend those integrations are live.
